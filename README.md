# Sistema Bancário em Java

## Sobre o projeto

Este projeto consiste em um sistema bancário desenvolvido em Java para praticar os fundamentos da programação e da programação orientada a objetos.

O sistema permite cadastrar clientes, criar contas bancárias e realizar operações básicas por meio de um menu no console.

## Funcionalidades

- Cadastro de clientes.
- Prevenção de cadastro de CPFs duplicados.
- Criação de contas bancárias.
- Consulta de clientes e contas.
- Depósitos e saques.
- Transferências entre contas.
- Consulta de saldo e extrato.
- Validação de operações bancárias.

## Tecnologias e conceitos

- Java
- Programação Orientada a Objetos (POO)
- Classes e objetos
- Encapsulamento
- Métodos e construtores
- Listas (`ArrayList`)
- Estruturas condicionais e de repetição

## Estrutura do projeto

- `Principal.java` — menu e interação com o usuário.
- `Banco.java` — gerenciamento de clientes, contas e operações bancárias.
- `Cliente.java` — representação dos clientes.
- `Conta.java` — dados e operações das contas bancárias.

## Como executar

1. Tenha o Java JDK instalado.
2. Baixe ou clone este repositório.
3. Abra os arquivos em uma IDE compatível com Java.
4. Execute a classe `Principal.java`.

## Objetivo

Projeto desenvolvido para fins educacionais, com o objetivo de praticar Java e desenvolver habilidades para futuros projetos de software.
